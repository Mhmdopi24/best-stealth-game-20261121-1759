The Moon Pearl — a top-down stealth game: sneak through a moonlit manor garden, dodge four patrolling guards and their vision cones, steal three moon pearls, and reach the golden gate unseen.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: every file the game loads lives under game/.
